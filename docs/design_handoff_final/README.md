# سوق تداول اللوحات — حزمة التصميم النهائية

ثلاث واجهات لمنصّة واحدة، بهويّة وقواعد مجال واحدة. ابدأ بالترتيب:

1. **`app/README.md`** — تطبيق الجوال (iOS/Android). فيه **رموز التصميم ومكوّن اللوحة وقواعد المجال وسجلّ القرارات** — مرجع مشترك مُلزِم للويب والإدارة.
2. **`web/README.md`** — الموقع (حاسوب/لوحي/جوال).
3. **`admin/README.md`** — لوحة الإدارة، و§4 فيه **جدول تطابق مسار الصفقة** بين الثلاث.

كل مجلّد فيه: ملف التصميم التفاعلي `.dc.html` (المرجع النهائي — افتحه في المتصفّح)، ومكوّن اللوحة، والشعارات، ورموز نظام التصميم، و`screenshots/final/`.

**قاعدة واحدة**: عند أي تعارض بين نصّ التعليمات وملف التصميم، **الملف هو المرجع**.

## البنية التحتية (تُضبط من لوحة الإدارة ← الإعدادات)
- **المتاجر**: Bundle ID / Package name / App ID / Team ID / SHA-256 / الإصدار وأدنى إصدار مدعوم / الروابط العميقة.
- **FCM**: الإشعارات وPush والبثّ الجماعي وتنبيهات محادثة نقل الملكية (data message فقط).
- **Cloudflare R2**: تخزين كل ملفات المنصّة والتطبيق، عامّ عبر CDN وخاصّ بروابط موقّعة.
- **Tap**: الدفع، وحوالات بنكية بتحقّق إداري.

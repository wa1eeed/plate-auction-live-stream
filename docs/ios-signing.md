# توقيع iOS — بمفتاحٍ واحد بلا Xcode

> ما يُضبط مرّةً في حساب أبل وجيت هب، فيبني البناء السحابيّ ويرفع إلى
> TestFlight بلا تدخّل. المصدر: [`mobile-ios.yml`](../.github/workflows/mobile-ios.yml)

## لماذا مفتاحٌ واحد لا شهادةٌ وملفّ تعريف

الطريق المعتاد يقتضي: توليد **طلب توقيع** في Keychain على ماك، ورفعَه لأبل،
وتنزيلَ شهادة، وتصديرَها `.p12` بكلمة، وإنشاءَ **ملفّ تعريف** باليد يطابق
معرّف الحزمة والقدرات — ثمّ تجديدَ ذلك كلَّه كلّ سنة.

و`xcodebuild -allowProvisioningUpdates` مع **مفتاح App Store Connect** يجعل
Xcode على خادم البناء يفعل ذلك كلَّه بنفسه: يُصدر الشهادة، ويسجّل معرّف
الحزمة، ويُنشئ ملفّ التعريف بالقدرات التي يطلبها ملفّ الاستحقاقات.

| | الطريق القديم | هنا |
| --- | --- | --- |
| يحتاج ماك بـXcode؟ | **نعم** | لا |
| عدد الأسرار | ٧ | **٤** |
| التجديد السنويّ | يدويّ | تلقائيّ |
| إن تسرّب | يُعاد بناء كلّ شيء | **يُبطَل المفتاح من اللوحة** |

## الأربعة

| السرّ | من أين |
| --- | --- |
| `APPLE_TEAM_ID` | [developer.apple.com/account](https://developer.apple.com/account) ← **Membership** — عشرة محارف |
| `APPSTORE_KEY_ID` | مع المفتاح أدناه |
| `APPSTORE_ISSUER_ID` | أعلى صفحة المفاتيح — واحدٌ للحساب كلّه |
| `APPSTORE_KEY_P8_BASE64` | ملفّ `.p8` مُرمَّزًا — أدناه |

### إنشاء المفتاح

**App Store Connect** ← Users and Access ← **Integrations** ← App Store
Connect API ← **Team Keys** ← `+`

- الاسم: أيّ شيء (`CI Build` مثلًا)
- الصلاحية: **App Manager**

> ولمَ App Manager لا Developer؟ لأنّ **إصدار الشهادات** يحتاجها. ودونَها
> يسقط البناء بـ«لا صلاحية لإنشاء شهادة» بعد أن يبدو كلُّ شيءٍ صحيحًا.

**والملفّ يُنزَّل مرّةً واحدة ولا يُعاد.** احفظه في مكانٍ آمن؛ وإن ضاع
فأبطِله وأنشئ غيره.

### ترميزه

```bash
base64 -i ~/Downloads/AuthKey_XXXXXXXXXX.p8 | pbcopy
```

الناتج في حافظتك — الصقه في السرّ مباشرةً.

> ⚠ **لا تلصق المفتاح في محادثة ولا في ملفّ داخل المستودع.** موضعُه الوحيد
> خانةُ السرّ في جيت هب.

### وضعها في جيت هب

المستودع ← **Settings** ← Secrets and variables ← **Actions** ←
`New repository secret`. أربع مرّات بالأسماء أعلاه حرفًا بحرف.

## أوّل تشغيل

```
Actions ← تطبيق iOS ← Run workflow
```

| ما ترى | ما يعنيه |
| --- | --- |
| «لا مفتاح توقيع — سيُبنى تحقّقًا من الترجمة فقط» | سرٌّ ناقص أو اسمُه مختلف |
| نجاحٌ وأثرٌ باسم `ios-<sha>` فيه `.ipa` | **تمّ** |

والرفع إلى TestFlight يقع عند **وسمٍ** لا عند تشغيلٍ يدويّ:

```bash
git tag v1.0.1 && git push origin v1.0.1
```

## ما يجب أن يسبق أوّل رفعٍ ناجح

- [ ] **تطبيقٌ مُنشأ في App Store Connect** بمعرّف `sa.nx.mazad` — الأرشفة
      تنجح بدونه، والرفع يسقط
- [ ] اتّفاقيات Apple Developer موقَّعة (Agreements, Tax, and Banking)
- [ ] **مفتاح APNs** مرفوعٌ في Firebase — وبدونه لا يصل iOS إشعارٌ واحد ولو
      نجح الإرسال ([`docs/notifications.md`](notifications.md))

## البناء رُفع ولا يظهر في TestFlight

الرفع الناجح ينتهي بـ`UPLOAD SUCCEEDED` ورقم تسليم. وظهورُه للمختبِرين يقتضي
ثلاثةً بعده:

| # | الشرط | أين |
| --- | --- | --- |
| ١ | **المعالجة تتمّ** | App Store Connect ← TestFlight ← يظهر «Processing» ٥–٣٠ دقيقة |
| ٢ | **إقرار التشفير** | يُحلّ من الكود — انظر أدناه |
| ٣ | **مجموعةُ اختبارٍ وأنت فيها** | TestFlight ← Internal Testing ← `+` ← أضف نفسك |

والثالث هو ما يُغفَل: **تطبيق TestFlight على جوّالك لا يعرض إلّا ما دُعيتَ
إليه.** فبناءٌ مكتملُ المعالجة بلا مجموعةٍ لا يظهر لأحد.

### إقرار التشفير — من الكود لا بسؤالٍ متكرّر

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

وبلا هذا المفتاح تسأل أبل عند **كلّ** رفعة: «هل يستعمل تطبيقك تشفيرًا؟» ويبقى
البناء `Missing Compliance` فلا يُثبَّت على جهاز مختبِرٍ واحد حتى يُجاب.

والإقرار صحيح: التطبيق لا يشفّر شيئًا بنفسه، بل يستعمل TLS الذي يوفّره
النظام — وهو في إعفاء القسم 740.17(b) من لوائح التصدير الأمريكية.

## الاستحقاقات

[`ios/App/App/App.entitlements`](../ios/App/App/App.entitlements) يحمل
`aps-environment: production` و`applinks:mazad.nx.sa` — وهما ما يقرؤه
التوقيع التلقائيّ ليطلب القدرتين من أبل.

> **وبلا هذا الملفّ يُنشأ ملفّ تعريفٍ بلا قدرة الإشعارات**، فيسقط
> `registerForRemoteNotifications` صامتًا ولا يصل إشعارٌ واحد — والبناء ينجح
> والرفع ينجح ولا شيء يشير إلى السبب.

و`production` لا `development`: ما يُبنى أرشيفُ إصدارٍ يذهب إلى TestFlight،
وخوادم APNs الإنتاجية لا تقبل رمزًا تطويريًّا.

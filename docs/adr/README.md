# سجلّ القرارات المعمارية (ADR)

كل ملف هنا يوثّق **قرارًا واحدًا**: سياقه، والبدائل التي رُفضت، ولماذا،
وما ثمنه. الهدف أن يفهم من يأتي لاحقًا سبب الاختيار فلا ينقضه بلا علم — أو
ينقضه عن بيّنة إن تغيّر السياق.

الصيغة: سياق ← قرار ← بدائل مرفوضة ← نتائج ← متى يُعاد النظر.
